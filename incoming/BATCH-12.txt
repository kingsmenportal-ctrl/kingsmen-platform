# BATCH 12 - Real Local Web Build / Dev-Server Readiness Gate

## Purpose

This batch creates a real local web build and dev-server readiness gate for the Free Destiny Map surface.

BATCH 11 proved browser-style form submit behavior using a temporary local proof server. BATCH 12 now inspects the actual repo web structure and records whether Kingsmen can safely attempt a real local web build or dev-server boot.

## What this batch checks

- root package manifest exists
- web app directory exists
- Free Destiny Map app route exists
- Free Destiny Map API form component exists
- Free Destiny Map client adapter exists
- public API endpoint contract exists
- runtime proof chain from BATCH 09, BATCH 10, and BATCH 11 exists
- data/local generated proof remains ignored
- package manager evidence exists
- build/dev scripts are discoverable if present
- dangerous production claims remain blocked

## Important proof rule

This batch is a readiness gate, not a production build claim.

If package scripts, dependencies, or app boot contracts are incomplete, the report must say so clearly. The validator passes when the readiness report is honest, safe, and complete.

## What this batch does not do yet

- no forced npm install
- no production Next.js build claim
- no long-running dev server
- no Playwright automation
- no Oracle deployment
- no Docker Compose boot
- no PostgreSQL database
- no Redis queue
- no email sending
- no payment processing
- no document upload
- no official application submission

## Oracle Lite impact

none_runtime_yet.

This is a source and local-readiness gate only.

## Next action

After validation, BATCH 13 should either repair the exact readiness blockers found by this report or create a controlled local web boot proof if the report says the repo is ready.

function exists(rel) {
  return fs.existsSync(path.join(root, rel));
}

function read(rel) {
  return fs.readFileSync(path.join(root, rel), "utf8").replace(/^\uFEFF/, "");
}

function parseJson(rel) {
  return JSON.parse(read(rel));
}

const failures = [];
const warnings = [];
const checked = [];

for (const file of requiredFiles) {
  checked.push(file);
  if (!exists(file)) failures.push(`Missing required file: ${file}`);
  else if (fs.statSync(path.join(root, file)).size === 0) failures.push(`Empty required file: ${file}`);
}

for (const file of upstreamFiles) {
  checked.push(file);
  if (!exists(file)) failures.push(`Missing upstream file: ${file}`);
  else if (fs.statSync(path.join(root, file)).size === 0) failures.push(`Empty upstream file: ${file}`);
}

if (exists("manifests/runtime/free-destiny-map-real-web-readiness-gate.json")) {
  const manifest = parseJson("manifests/runtime/free-destiny-map-real-web-readiness-gate.json");
  if (manifest.productionReady !== false) failures.push("Manifest must keep productionReady false.");
  if (manifest.storesProductionData !== false) failures.push("Manifest must declare storesProductionData false.");
  if (manifest.takesPayment !== false) failures.push("Manifest must declare takesPayment false.");
  if (manifest.sendsEmail !== false) failures.push("Manifest must declare sendsEmail false.");

  if (manifest.submitsOfficialApplications !== false) failures.push("Manifest must declare submitsOfficialApplications false.");

  ["scripts/runtime/Invoke-FreeDestinyMapRealWebReadinessGate.ps1", ["prove-free-destiny-map-real-web-readiness.mjs", "does not claim production"]],
  ["scripts/proof/prove-free-destiny-map-real-web-readiness.mjs", ["READY_FOR_CONTROLLED_LOCAL_BOOT", "BLOCKED_WITH_REPAIR_ACTIONS", "canAttemptLocalWebBoot", "dependency-install-evidence-present"]],

for (const [file, tokens] of tokenChecks) {

    failures.push("Blocked readiness proof must list blockers.");

  .filter((item) => !item.includes("prove-free-destiny-map-real-web-readiness.mjs"));

  for (const [pattern, label] of forbiddenRuntimePatterns) {
    if (pattern.test(content)) failures.push(`${file} contains forbidden runtime pattern: ${label}`);

const passed = failures.length === 0;

const report = {

fs.writeFileSync(reportPath, `${JSON.stringify(report, null, 2)}\n`, "utf8");

console.log(JSON.stringify(report, null, 2));
if (!passed) process.exit(1);
