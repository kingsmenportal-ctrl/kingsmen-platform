# N_PROVIDER.5 — 25 Connected Apps + Supabase Reality Map

N_PROVIDER.5 maps all 25 visible ChatGPT connected/provider apps into Kingsmen-safe provider classes.

It supersedes N_PROVIDER.4 because Supabase is now visible, increasing the provider count from 24 to 25.

## Provider law

Visible app does not automatically mean callable.

Callable app does not automatically mean production-safe.

Production use requires:
1. visibility recorded
2. callable/action surface tested
3. secrets boundary documented
4. no secrets in repo
5. candidate-data boundary documented
6. validator created
7. report written
8. founder approval recorded for high-risk use
9. repo proof committed
10. runtime use enabled only after gate passes

## Permanent Kingsmen rule

AI may recommend.
Scripts must validate.
Backend must enforce.
PowerShell / GitHub Actions must prove.
GitHub must preserve.
Founder must approve high-risk actions.
