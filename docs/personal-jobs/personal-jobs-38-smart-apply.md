# PJ38 — Smart Apply Workbench

This module upgrades the Apply page from a manual form into a smart application workbench.

## Added

- CV/document upload with extraction attempt
- DOCX extraction through Mammoth
- PDF extraction through pdf-parse when supported locally
- Smart profile merge from CV text
- Document vault list
- Real opportunity queue
- Application pack generator
- Proof capture
- Professional application workspace UI

## User reality

A user should not type every detail already inside their CV. Kingsmen must read the CV where possible, prefill the profile, let the user correct it, and reuse it across applications.

## Boundary

Kingsmen does not invent experience, qualifications, certificates, references, identity numbers, or proof. It only extracts and reuses candidate-provided information.
