# PERSONAL-JOBS-29 - Proof Review Board / Status Advancement Control

PJ29 consumes PJ28 daily worklist items and creates a proof review board for status advancement decisions.

## Input

`data/personal-job-desk/daily-worklist.local.json`

## Output

`data/personal-job-desk/proof-review-board.local.json`

## Route

`/personal-job-desk/proof-review-board`

## API

`/api/personal-jobs/proof-review-board`

## What PJ29 creates

- Proof review items
- Founder/operator decision fields
- Status advancement target controls
- Candidate-safe proof visibility rules
- Audit rules

## Safety

PJ29 does not submit applications, send email, send WhatsApp, send SMS, contact employers, touch payments, bypass login, bypass OTP, bypass CAPTCHA, or mutate upstream tracker/worklist records automatically.
