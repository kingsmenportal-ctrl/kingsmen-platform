# PERSONAL-JOBS-24 - Candidate Application Tracker / Proof-Backed Progress View

PJ24 consumes PJ23 manual submission workbench records and creates a candidate-safe application tracker.

## Input

`data/personal-job-desk/manual-submission-workbench.local.json`

## Output

`data/personal-job-desk/application-tracker.local.json`

## Route

`/personal-job-desk/application-tracker`

## API

`/api/personal-jobs/application-tracker`

## What PJ24 creates

- Candidate-safe application status
- Proof-backed progress steps
- Timeline summary
- Candidate note/acknowledgement capture
- Outcome visibility without guarantees

## Safety

PJ24 does not submit applications automatically, email employers, send WhatsApp messages, touch payments, bypass login, bypass OTP, bypass CAPTCHA, or claim production readiness.
