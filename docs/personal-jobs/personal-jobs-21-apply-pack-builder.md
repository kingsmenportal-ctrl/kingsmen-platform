# PERSONAL-JOBS-21 - One Profile Apply Pack Builder / CV + Motivation Drafts / Manual Submission Packet

PJ21 converts PJ20B-ready job leads into reviewable application packs using one saved profile.

## Input

- `data/personal-job-desk/opportunity-quality-gate.local.json`
- `data/personal-job-desk/one-profile.local.json`

## Output

`data/personal-job-desk/application-packs.local.json`

## Route

`/personal-job-desk/apply-pack-builder`

## API

`/api/personal-jobs/apply-pack-builder/build`

## What PJ21 creates

- CV focus points
- Motivation letter draft
- Manual application steps
- Proof capture checklist
- Review warnings
- Human approval boundary

## Safety

PJ21 does not submit applications, email employers, send WhatsApp messages, touch payments, bypass login, bypass OTP, bypass CAPTCHA, or claim production readiness.
