# PJ36 — Personal Job Desk Platform Shell

This module fixes the problem where Kingsmen Personal Job Desk behaved like disconnected pages instead of a real platform.

## Added

- Persistent left navigation
- Top bar with Back, Forward, Home and Refresh
- Menu drawer
- Current page indicator
- Quick action buttons
- Connected home dashboard
- Links to Apply Now, Opportunity Scout and Document Pack
- Mobile navigation placeholder structure

## User reality

A candidate must not feel trapped inside one page. They must be able to move around the job platform like a real application:
Home → Scout → Import → Apply → Documents → Proof.

## Boundary

This is platform navigation and user experience wiring. It does not claim final production readiness, payment runtime, external database runtime, or legal auto-submission.
