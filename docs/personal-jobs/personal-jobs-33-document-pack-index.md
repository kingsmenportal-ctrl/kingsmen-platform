# PERSONAL-JOBS-33 - Candidate Document Pack Index / Application Evidence Attachment Map

PJ33 consumes PJ32 candidate-safe snapshot items and creates a document pack readiness index with application evidence attachment mapping.

## Input

`data/personal-job-desk/public-snapshot.local.json`

## Output

`data/personal-job-desk/document-pack-index.local.json`

## Route

`/personal-job-desk/document-pack-index`

## API

`/api/personal-jobs/document-pack-index`

## What PJ33 creates

- Document pack readiness index
- Application evidence attachment map
- Truthful document slots
- Candidate instructions
- Exportable markdown document pack index

## Safety

PJ33 does not create documents, invalid documents, submit applications, contact employers, expose sensitive proof, send email, send WhatsApp, send SMS, touch payments, or claim production readiness.
