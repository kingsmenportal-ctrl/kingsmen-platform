# Kingsmen Apply Desk - Today Mode

Route: `/personal-job-desk/apply-now`

This is the practical same-day Apply Desk. It allows the user to:

- Save one candidate profile
- Upload real documents locally
- Open real opportunity sources
- Add jobs, learnerships, internships, funding or bursary opportunities from real links
- Generate reusable application packs
- Copy application text
- Open email draft when an email address exists
- Capture proof after manual application

## Important boundary

This does not fake submissions, bypass portals, bypass logins, bypass OTP/CAPTCHA, invent jobs, invent documents or guarantee employment.
