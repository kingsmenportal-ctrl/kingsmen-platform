# TOOLS-01 — Connected Tool Activation Gates

TOOLS-01 turns N_PROVIDER.5 into a safe tool activation gate layer.

It does not activate production use.

It creates rules for:
- callable tools
- visible but untested tools
- off/untrusted tools
- high-risk providers
- founder approval
- no-secrets boundary
- candidate-data boundary
- proof report requirement

Permanent rule:

AI may recommend.
Scripts must validate.
Backend must enforce.
PowerShell / GitHub Actions must prove.
GitHub must preserve.
Founder must approve high-risk actions.
