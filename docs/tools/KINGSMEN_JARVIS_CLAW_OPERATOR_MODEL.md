# KINGSMEN JARVIS + CLAW OPERATOR MODEL

## Purpose

Jarvis and OpenClaw are Kingsmen helper tools, not production authority.

## Roles

Jarvis:
- local command brain
- summarizes safe pasted proof
- recommends next safe command
- does not execute repo changes

OpenClaw:
- local operator assistant
- helps founder understand proof, tools, and next steps
- does not run production actions
- does not use WhatsApp yet

PowerShell:
- executes approved local commands

GitHub:
- stores proof

Validators:
- judge whether something is real

Founder:
- approves high-risk actions

## Current Status

Jarvis: installed, sandboxed, experimental.
OpenClaw: installed, config valid, gateway works, boundary partial only.

## Rule

No AI tool becomes trusted because it talks well.
It becomes trusted only after boundary tests, reports, validator checks, and Git proof.
