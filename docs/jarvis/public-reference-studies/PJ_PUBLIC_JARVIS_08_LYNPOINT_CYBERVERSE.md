## 2. What this project represents

CyberVerse represents the real-time digital-human / voice-agent direction.

It is not mainly a repo-builder assistant. It is closer to:

```txt
voice-first interaction
+ streaming transport
+ persona memory
+ tool use
+ RAG retrieval
+ optional visual/avatar surface
+ self-hosted agent runtime
```

This is important for Kingsmen because the founder wants Jarvis to feel responsive, conversational, powerful, and present. CyberVerse is a useful reference for the presence/streaming side of Jarvis, not for Kingsmen business authority.

---

## 3. What Kingsmen should learn

Kingsmen Jarvis needs more than a text box. It needs a responsive interaction surface.

Useful lessons:

1. Real-time voice should feel low-latency.
2. Streaming response is better than waiting for one large answer.
3. Voice-first agents need turn-taking, interruption handling, and session continuity.
4. Persona memory must be separated from production truth.
5. Tool use must be routed through policy gates.
6. RAG can help answer from Kingsmen doctrine, repo docs, public sources, and evidence ledgers.
7. Digital-human/avatar visuals are optional and must not come before core functionality.

## 5. What Kingsmen must reject

Kingsmen must reject these patterns:

```txt
AI avatar as authority
always-on camera/mic by default
unbounded persona memory
production tool calls from conversational excitement
WebRTC/voice layer bypassing backend state machine
RAG over unverified sources presented as truth
candidate data stored in personality memory
visual polish before functional repo builder
```

Voice, avatar, and digital presence must never bypass Kingsmen law.

## 7. Kingsmen build priority

CyberVerse-style features should not be first.

Build order:

```txt
1. Text command engine
2. Doctrine/policy gate
3. Command registry
4. Builder core
5. Evidence ledger
6. Validator runner
7. App connector router
8. Voice input and speech output
9. Streaming response composer
10. WebRTC/live voice gateway
11. Optional avatar/digital-human surface
```

This means CyberVerse contributes mostly to phases 8-11, not phases 1-7.
