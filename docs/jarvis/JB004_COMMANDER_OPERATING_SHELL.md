# JB-004 — Jarvis Commander Operating Shell

Status: built in repo, local proof still required.

## Commander lock

Jarvis must become the live Kingsmen Commander operating shell. It must not present as a wallpaper, a generic dashboard, or a set of disconnected add-on cards.

## Implementation target

The `/jarvis` page must show one disciplined system:

- command centre
- voice command surface
- visual feed surface
- live status ledger
- evidence drawer
- live output window
- real-build lock
- proof honesty message
- Commander-only language

## Non-negotiable

Visual identity must be treated as the operating system surface. The visual layer is not decoration.

## Proof rule

GitHub commit proves repo preservation only. Local Windows CMD output and build output are still required before claiming the local Jarvis is working on the Commander machine.
