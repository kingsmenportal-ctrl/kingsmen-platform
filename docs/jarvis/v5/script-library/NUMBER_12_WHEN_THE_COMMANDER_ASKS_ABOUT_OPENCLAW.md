## 2. What Number 12 means in plain Kingsmen terms

OpenClaw is a controlled gateway.

It may support Kingsmen by helping Jarvis route approved work to external agents, tools, browser sessions, research tasks, or controlled command surfaces.

OpenClaw may help with:

- controlled agent routing,
- external tool orchestration,
- research delegation,
- messaging or channel gateway tasks,
- approved command execution paths,
- returning findings to Jarvis,
- routing task results back to the evidence ledger,
- helping separate specialist agents from the Jarvis core.

But OpenClaw must never become:

- final truth,
- final authority,
- hidden decision-maker,
- payment authority,
- official-status authority,
- candidate-outcome authority,
- document authority,
- uncontrolled automation,
- a bypass around Jarvis policy,
- a bypass around Commander approval,
- a replacement for PostgreSQL Truth Vault,
- a replacement for backend state,
- a replacement for evidence.

OpenClaw’s correct place is after Jarvis routing and policy. It receives bounded tasks and returns evidence. It does not rule the system.
