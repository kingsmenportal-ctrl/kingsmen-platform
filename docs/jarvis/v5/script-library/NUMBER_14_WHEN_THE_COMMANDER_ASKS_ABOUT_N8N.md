## 1. Operating source line for Number 14

The operating line for **Number 14 — When the Commander Asks About n8n** is:

> “Commander, n8n shall remain a thin workflow worker. It may execute approved tasks, but it must not become the brain, truth, or hidden decision-maker of Kingsmen.”
