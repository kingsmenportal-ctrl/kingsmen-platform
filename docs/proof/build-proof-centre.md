# BATCH 03 - Build Proof Centre

Build Proof Centre is the founder-facing proof surface for Kingsmen.

It reads validator reports and explains what is built, what is validated, what failed, what is pending validation, what the next safe action is, and what the Oracle Lite impact is.

Build Proof Centre must never claim production readiness just because files exist.

A module is only VALIDATED when its report says passed true and failed_checks is empty.

Oracle Lite impact: none_runtime_yet.
