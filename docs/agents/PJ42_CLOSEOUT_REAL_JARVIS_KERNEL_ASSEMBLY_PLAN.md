PJ42 is not yet the full runtime implementation. PJ42 is the law, design, routing, evidence, and validator foundation that prevents Jarvis from becoming a random chatbot or uncontrolled agent.

PJ43 must use this package to implement the actual runtime code.

## Runtime Assembly Rule

Every runtime module in PJ43 must map back to a PJ42 law file or manifest.

If a future Jarvis feature has no PJ42 law, command, intent, adapter, evidence rule, or visual surface, it is not allowed until registered.
