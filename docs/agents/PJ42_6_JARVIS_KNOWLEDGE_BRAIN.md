# PJ42.6 — Jarvis Knowledge Brain

Status: Founder-locked build doctrine
Parent: PJ42.5 — Jarvis Source Confidence Engine
Issue: #17

## Purpose

PJ42.6 creates the Jarvis Knowledge Brain.

The Knowledge Brain is the safe retrieval and memory layer that lets Jarvis answer Kingsmen questions intelligently without guessing, drifting, or leaking private records.

Jarvis must know Kingsmen from approved doctrine, repo files, build records, source intelligence, and approved summaries — not from raw private operational data.

## Core Law

Jarvis must search approved Kingsmen knowledge before guessing about Kingsmen.

Private candidate records, private payment records, raw operational rows, authentication material, browser sessions, and unapproved personal data are not Jarvis memory.

## Master Flow

```text
Commander Message
  -> Intent Router
  -> Command Registry
  -> Policy Gate
  -> Tool Router
  -> Knowledge Brain
  -> Source Confidence Engine
  -> Evidence Ledger
  -> Answer Composer
```

## What Jarvis May Know

Jarvis may retrieve and summarize:

- Kingsmen doctrine and laws,
- PJ42 Jarvis law package,
- N-series architecture,
- workflow registry,
- pricing and business pack,
- route universe and public source intelligence,
- GitHub/repo build evidence,
- Founder decisions and command outcomes,
- system incident summaries,
- visual HUD/product decisions,
- safe public opportunity intelligence.

## What Jarvis Must Not Store As Memory

Jarvis must not store:

- raw candidate records,
- private payment details,
- private documents,
- authentication material,
- browser session material,
- production access material,
- unapproved personal data,
- fake proof or unsupported status claims.

## Retrieval Rule

For every Kingsmen-specific answer, Jarvis must prefer:

1. Current repo law/manifests
2. Locked doctrine files
3. Validated build records
4. GitHub issues and commit evidence
5. Public source intelligence with confidence band
6. Safe summarized memory
7. Visible chat context only when no source exists

## Answer Rule

Jarvis answers must state when knowledge is:

- locked,
- validated,
- planned,
- draft,
- missing proof,
- stale,
- conflicting,
- blocked.

## Final Rule

The Knowledge Brain makes Jarvis intelligent, but Kingsmen law makes Jarvis safe.

Jarvis must retrieve before it claims.
