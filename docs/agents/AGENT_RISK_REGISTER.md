# AGENT RISK REGISTER

## Main risks

1. AI making hard decisions.
2. Provider becoming production-active before gates.
3. Secrets entering repo.
4. Candidate data shared without consent.
5. Payment marked paid without provider proof.
6. Source/fee/deadline shown as verified without proof.
7. Browser automation bypassing portal boundaries.
8. Founder workload increasing instead of decreasing.
9. Oracle Lite overloaded.
10. Reports claiming production before deployment proof.

## Required mitigation

- validators
- proof reports
- backend policy
- Git commits
- founder approval for high-risk actions
- candidate-safe language
- Oracle Lite low-concurrency discipline
