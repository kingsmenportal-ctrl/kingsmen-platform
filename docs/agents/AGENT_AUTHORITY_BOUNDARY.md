# AGENT AUTHORITY BOUNDARY

## Hard authority rule

Agents are not sovereign authority.

AI may recommend.
Scripts must validate.
Backend must enforce.
PowerShell and GitHub Actions must prove.
GitHub must preserve.
Founder must approve high-risk decisions.

## Blocked without approval

- live payments
- refunds
- production database activation
- public deployment
- partner identity sharing
- candidate data export
- bulk outreach
- official application submission
- live AI automation
- source freeze or unfreeze
- growth cap increase
- stop-selling override
- Oracle paid resource activation

## Proof boundary

Every agent output must become one or more of:

- repo file
- manifest entry
- validator check
- proof report
- Git commit
- founder action packet
