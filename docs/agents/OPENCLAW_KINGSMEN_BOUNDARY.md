# Kingsmen OpenClaw Boundary

Status: RESEARCH_SANDBOX_ONLY

OpenClaw may be used as inspiration/tooling for a Founder Command Agent.

Allowed:
- local sandbox install
- research
- command-routing pattern
- skill/agent structure study
- no-secret demos

Blocked:
- no Oracle private keys
- no GitHub tokens
- no Supabase service_role
- no payment secrets
- no candidate data
- no production shell
- no autonomous deploy
- no refund/payment approval
- no official application submission

Kingsmen rule:
AI may recommend.
Scripts must validate.
Backend must enforce.
PowerShell and GitHub Actions must prove.
Founder must approve high-risk actions.
