# AGENTS-01 — Kingsmen Agent System

AGENTS-01 adapts the Kingsmen agent notes into a real build acceleration system.

Agents do not replace proof.

Permanent law:

AI may recommend.
Scripts must validate.
Backend must enforce.
PowerShell and GitHub Actions must prove.
GitHub must preserve.
Founder must approve high-risk decisions.

## Agent classes

- AI_REASONING_AGENT
- RULE_VALIDATOR_AGENT
- BACKEND_AUTHORITY_AGENT
- POWERSHELL_BUILD_AGENT

## Purpose

Kingsmen uses agents to build faster without becoming uncontrolled.

AI agents think, design, review, draft, and recommend.
Rule agents validate, block, count, scan, and report.
Backend authority agents enforce state, policy, consent, payment, source, and privacy.
PowerShell build agents materialize files, run validators, write reports, and prepare deployment.

No agent may silently activate production, payments, candidate data sharing, official application actions, live AI automation, bulk outreach, or provider secrets.
