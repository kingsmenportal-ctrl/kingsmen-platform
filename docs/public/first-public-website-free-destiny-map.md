# BATCH 04 - First Public Website + Free Destiny Map Shell

## Purpose

This batch creates the first public Kingsmen website shell and Free Destiny Map entry surface.

It is not yet a live production website, payment system, real submission engine, or connected backend intake. It is a validated public-facing shell that explains Kingsmen safely and gives the user a first route-aware entry point.

## Public promise

Kingsmen helps users map their movement across:

- higher education
- TVET
- SETA / learnership routes
- internships
- apprenticeships
- employment
- NSFAS and bursary readiness
- accommodation needs
- CV readiness
- document readiness
- source confidence
- fallback / Phoenix direction

## Hard safety rules

Kingsmen must not claim:

- guaranteed acceptance
- guaranteed NSFAS/funding
- guaranteed job placement
- guaranteed accommodation
- official partnership with an institution unless verified
- current opening/deadline/fee without source verification
- production readiness before runtime proof

## Free Destiny Map purpose

The Free Destiny Map is a fast first-intake route map.

It helps the user tell Kingsmen:

- who they are
- what they want
- whether they are confused or know the route
- what province/location matters
- whether they need accommodation
- whether they need CV help
- whether they need funding/NSFAS/bursary support
- whether they heard about a random bursary, job, college, learnership, accommodation, or training provider
- what documents they already have

At this shell stage, the form is not yet connected to backend storage.
