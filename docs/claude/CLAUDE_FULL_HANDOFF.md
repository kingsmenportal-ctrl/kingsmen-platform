## 1. Why this handoff exists

Previous work repeatedly fell into this loop:

1. A huge script was generated.
2. It partially worked or wrote files into the wrong place.
3. The live output drifted from the approved design or missed important systems.
4. The Commander rejected the result.
5. A new huge script promised to fix everything.
6. The same drift repeated.

The root problem was no single spec being treated as law. That is now fixed through the locked product spec and this handoff.
