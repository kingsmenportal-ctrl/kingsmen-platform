# CLAUDE MEDIA / CHAT / PROMPT INTAKE GUIDE

This repo contains the durable Kingsmen / Jarvis source of truth, but not every item from past chats, screenshots, videos, generated images, or pasted prompts is guaranteed to be inside the repo.

Use this guide when the Commander says Claude must have everything.

## 1. Treat repo evidence as primary

Primary evidence lives in:

- `docs/jarvis/JARVIS_LOCKED_PRODUCT_SPEC.md`
- `CLAUDE.md`
- `docs/claude/CLAUDE_FULL_HANDOFF.md`
- `docs/claude/CLAUDE_REPO_AND_EVIDENCE_READING_ORDER.md`
- `reports/jarvis/`
- `apps/web/`
- `packages/`
- `prompts/`
- `config/`

## 2. Treat missing media honestly

If a screenshot, video, prompt, or chat transcript is not in the repo, do not guess its details.

Ask the Commander to place it in one of these folders:

- `evidence/media/screenshots/`
- `evidence/media/videos/`
- `evidence/media/prompts/`
- `evidence/media/transcripts/`
- `docs/claude/imported-chat-logs/`

## 3. Minimum metadata for every imported item

Each imported media/chat/prompt item should have:

- file name
- source chat/tool/app
- date if known
- why it matters
- whether it is approved, rejected, or reference only
- what Jarvis rule it affects

## 4. Known approved/rejected categories

Approved direction:

- premium futuristic command centre
- obsidian / navy / royal blue / cyan / gold
- central Jarvis command brain/orb
- live clickable systems
- agents, robots, tools, apps, providers, N00-N20, evidence, voice, OpenClaw, Playwright visible

Rejected direction:

- black/white Jarvis screen
- monochrome static wireframe
- generic dashboard
- fake provider connections
- fake live numbers
- hiding small details like greetings, voice, scripts, apps, agents, robots, tools

## 5. What Claude should do when media is added

1. Read the locked spec first.
2. Read this intake guide.
3. Inspect the added files.
4. Create or update an index file describing them.
5. Link any approved rule into `docs/jarvis/JARVIS_LOCKED_PRODUCT_SPEC.md` only after Commander approval.

Do not silently change doctrine from media alone.
