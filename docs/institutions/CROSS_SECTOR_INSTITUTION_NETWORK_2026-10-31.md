# Cross-sector institution network — 31 October 2026

The national institution network is cross-sector. Education and skills are one sector within the canonical registry. The candidate retains one Kingsmen account, profile and workbench.

The next implementation batch extends the existing `route_providers` table with sector, subtype, registration reference, parent entity, aliases, capabilities, service area and source freshness fields. It does not create a parallel institutions table.

Official source anchors include the GCIS government/public-entity/municipal directories, CIPC enterprise search, FSCA authorised-provider search, SHRA's 2026 social-housing register, the SASSA official government profile, and the National Department of Health / NHIE Master Health Facility List documentation.

Municipal Treasury data is supplemental, not the legal municipality identity source. NPO registration guidance is not a live NPO register. Health facility API documentation is not Kingsmen API access; partner onboarding, assigned credentials, sandbox conformance and production approval remain required.

Proposed migration 0101 and its five initial cross-sector records remain review-only. No partnership, live integration, open service, application receipt or outcome is asserted.
