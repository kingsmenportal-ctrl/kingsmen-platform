# Founder Summary — N21.2

N21.2 has made the first public repo integration practically useful.

Docling is now represented as a Kingsmen smart-intake adapter.

A CV/document text extraction can now be converted into draft candidate fields such as name, email, phone, address, qualification, school, skills, certificates, work experience, and driver licence.

The system deliberately refuses to write candidate truth directly. It creates review fields only.

This solves the founder complaint that candidates should not retype information already present in CVs and documents.
